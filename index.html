Clover & Kettle Automation

A quieter kind of day.

A private publishing tool operated by the owner of Clover & Kettle, a channel sharing original AI-assisted countryside visual stories.

What the application does

The integration uses self-hosted n8n and YouTube API Services to upload the owner's original videos, set titles, descriptions and publication settings, and check upload and processing status. It is intended to support publishing to YouTube alongside a separate Facebook publishing workflow.

Google OAuth authorizes access to the owner's YouTube channel. Google credentials are entered on Google's own sign-in pages; the application does not ask for a Google password.

Who can use it

This is an owner-operated integration being configured for private use. It is not a public service accepting customer accounts. This website provides application information; it is not the n8n dashboard or a sign-in portal.

Before authorizing the integration, review the privacy policy.

Terms of use

The integration is for the channel owner's authorized publishing activities. The operator is responsible for content rights, accurate metadata, required AI disclosures, and publication settings. By using this application, you agree to be bound by the YouTube Terms of Service and this application's privacy policy.

The integration is provided as available, without a guarantee of continuous operation, audience reach, or monetization. Authorization can be revoked at any time.

Contact

For application questions or privacy requests, contact the operator through this project's GitHub issues. Issues are public: do not include passwords, tokens, or private account information.
