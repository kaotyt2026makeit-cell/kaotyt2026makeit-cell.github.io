Privacy policy

This policy applies to Clover & Kettle Automation, the private n8n publishing integration operated by the owner of the Clover & Kettle channel, and this information website.

Information accessed and used

The integration uses YouTube API Services. Depending on the permissions granted, it accesses channel identifiers and basic channel information, video identifiers, titles, descriptions, privacy and scheduling settings, and upload or processing status. It submits the owner's selected video files and metadata to YouTube.

OAuth access and refresh tokens are stored in the owner's self-hosted n8n credentials store to maintain the authorized connection. Workflow records may contain video identifiers, metadata, status responses, and error details. The tool does not collect Google account passwords or request access to Gmail, Google Drive, or contacts.

Purpose and sharing

Information is used to identify the correct channel, carry out authorized uploads and metadata changes, check results, prevent duplicate publishing, and troubleshoot failures. Google receives the files and metadata submitted to YouTube.

The hosting infrastructure processes stored credentials and workflow records on the operator's behalf. The separate Facebook workflow may receive the same owner-supplied original media and its own caption; it does not require transferring private Google account data or OAuth tokens to Facebook.

Google API data is not sold, used for advertising profiling, or used to train AI models. Private Google API data and OAuth tokens must not be included in requests to caption-generation services. Access is limited to the operator and service providers needed to run the integration.

Storage, retention and deletion

Credentials remain in the private n8n installation, not this public website or its source repository. The operator restricts access and removes tokens, associated API data, and execution records when no longer needed. Stored YouTube API metadata must be refreshed or deleted within 30 days as applicable under YouTube API policies.

The channel owner can request deletion through the contact link below or directly remove the n8n credential and associated workflow data. Deletion requests and removal of authorized API data after revocation will be completed as soon as possible and within 30 days, including retained copies under the operator's control. These are operating commitments that apply before ongoing publishing is enabled.

Removing local records does not delete videos already published on YouTube or Facebook. Those are managed separately through the respective platform.

Revoking access

You can revoke this application's Google access through Google account permissions. Revocation prevents further authorized Google API access. Contact the operator to request deletion of previously stored data as described above.

Website hosting and cookies

This static website does not add analytics, advertisements, forms, or tracking cookies. GitHub Pages hosts it and processes visitor information, including IP addresses, for hosting and security under the GitHub Privacy Statement. Google's authorization pages and the private n8n dashboard may use their own session cookies.

Google policies

Google's processing is described in the Google Privacy Policy. Use of this application is also subject to the YouTube Terms of Service. Use and transfer of Google API information will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Contact and changes

For questions, complaints, or deletion requests, contact the operator through GitHub issues. Do not post sensitive data publicly; request a private follow-up if needed. This policy will be updated when data practices change, and any additional access requires the appropriate authorization.
